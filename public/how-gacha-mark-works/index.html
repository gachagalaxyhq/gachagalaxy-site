[ How Gacha Mark works ]

One record per PSA cert, that anyone can check.

A Gacha Mark is a public record for one graded card. It is keyed by grader and cert number, so a single cert has a single record, and anyone can see who published it and whether it still stands.

[ The steps ]

From request to public record

Seven steps. Nothing is published automatically.

  • 01

    Request

    Add a PSA cert to My Collection and ask for a Mark. You can follow the status and the reason for every decision, and cancel at any time.

  • 02

    Grading check

    We read the grading record for that cert number: card, set, number and grade. If the cert can't be found, or the details don't match, the request stops here.

  • 03

    Reference value

    We set a value from public marketplace prices for the same card at the same grade. No Mark below $50 or below medium confidence. Prices are asking prices, not completed sales.

  • 04

    Human review

    A person checks the request before anything is published. A grading record existing is never enough on its own, and every decision is logged with a reason.

  • 05

    Recorded onchain

    The Mark is written to a registry on Robinhood Chain, keyed by grader and cert number: value, grade, publish date and publisher.

  • 06

    Anyone can check it

    Every Mark has a public page and a QR code. The page reads the registry directly, so you can compare what the site shows with what the chain holds.

  • 07

    Kept current

    Each Mark lasts 30 days and is rechecked before then. If the value drops under $50 or moves sharply, it goes back for review. A revoked Mark is labelled as revoked, not removed.

[ Limits ]

What a Mark shows, and what it doesn't

A Mark is a record about a cert number. It is not an inspection of the slab in your hand.

It shows

  • That this cert has one public record, and who published it
  • The grade from the grading record at the time of the check
  • A reference value and the date it was set
  • Whether the record is active or revoked

It does not show

  • That a physical slab is genuine. A copied label can carry a real cert number
  • Who owns the card, or where it is held
  • A guaranteed price. Values come from asking prices, not completed sales
  • Anything about grades from other graders. Marks cover PSA only for now

Check the slab itself and the grader's own cert lookup before you buy. Gacha Mark is in pre-production and may change.
